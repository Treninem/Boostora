# Отчёт выпуска Boostora v3.3.0

## Проверено локально

- синтаксис всех Python-файлов;
- синтаксис JavaScript Mini App;
- фильтрация пользовательского каталога только по Telegram;
- включение всех Telegram-услуг одним действием;
- включение/отключение отдельной услуги;
- недоступность услуг других площадок через публичный метод;
- папки, подпапки и постраничная выборка;
- отсутствие служебных терминов в основных пользовательских текстах;
- наличие и подключение всех 14 премиальных изображений;
- отсутствие БД, `.env`, логов, кэша и известных секретов в RUNTIME.

## Не выполнялось локально

Реальные запросы к Boostore, платежи Telegram Stars и полный запуск на Bothost требуют действующих ключей и сетевого окружения. Их нужно проверить после деплоя.
