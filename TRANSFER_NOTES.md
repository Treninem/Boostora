# Boostora v3.7.0 — контрольная точка

Следующая работа начинается от **v3.7.0**. Внешнее меню намеренно держим простым: Главная / Работа / Кабинет. Новые функции по возможности прячем внутрь существующих смысловых разделов, а не добавляем новые верхние кнопки.

Канон ядра: WAL + BEGIN IMMEDIATE для критических транзакций, сериализация Mini App mutations по пользователю, безопасный retry только read-only запросов, `/health/ready`, heartbeat worker, owner diagnostics. Все правила v3.6.x для групп и автопроверки заданий сохранены.
