# Запуск Boostora v3.5.0 на Bothost

## 1. Архив

Для нового деплоя используйте `Boostora_v3.5.0_RUNTIME.zip`. Распакуйте его в корень репозитория.

## 2. Команда запуска

```bash
python3 main.py
```

## 3. Основные переменные

Скопируйте значения из `.env.example` в панель Bothost. Минимально необходимы:

```env
BOT_TOKEN=ВАШ_ТОКЕН
ADMIN_IDS=2097006037
BOT_DATA_DIR=/app/data
DB_PATH=boostora.db
WEBAPP_ENABLED=1
WEBAPP_REQUIRED=1
WEBAPP_HOST=0.0.0.0
PORT=3000
WEBAPP_URL=https://boostorabot.bothost.tech
DROP_PENDING_UPDATES=0
```

Для Boostore дополнительно:

```env
BOOSTORE_ENABLED=1
BOOSTORE_API_URL=https://boostore.ru/api/v2
BOOSTORE_API_KEY=ВАШ_КЛЮЧ
BOOSTORE_DEFAULT_MARKUP_PERCENT=35
BOOSTORE_AUTO_SYNC=0
BOOSTORE_AUTO_ORDER_ENABLED=0
```

Настоящие ключи храните только в переменных Bothost. Не помещайте их в код, архив или GitHub.

## 4. Первый запуск

После деплоя проверьте:

- `/health` отвечает без ошибки;
- `/start` показывает соглашение;
- отказ блокирует функции;
- принятие открывает Mini App;
- владелец видит закрытое управление;
- обычный пользователь не видит административные разделы.

## 5. Живая проверка платежей

Сначала купите минимальный пакет кредитов. Stars должны начислить кредиты один раз, а не оплатить рекламу или внешнюю услугу напрямую.

## 6. Живая проверка Boostore

1. Синхронизируйте каталог из закрытого управления.
2. Выберите конкретную услугу как обычный пользователь.
3. Проверьте текущую цену и наценку.
4. Создайте один минимальный тестовый заказ.
5. Только после успешного теста включите `BOOSTORE_AUTO_ORDER_ENABLED=1`.

## 7. Проверка рекламной сети

Добавьте бота администратором в тестовый канал или чат от 100 участников. Выдайте права на публикацию и создание пригласительных ссылок. Проверьте автоматическое появление площадки, расписание, публикацию, отслеживание и реакцию системы на снятие прав.

## 8. База и резервные копии

Рабочая БД должна находиться в `/app/data`. Не удаляйте каталог данных при обычном обновлении. Перед крупным обновлением сохраните резервную копию.
