# Boostora v3.7.0 — simplified shell / hardened core

Крупный релиз без раздувания меню.

## UI
- 3 нижние вкладки вместо 5: Главная, Работа, Кабинет.
- Главная показывает только состояние и два основных действия.
- Кошелёк, профиль, Standard/PRO, документы, дополнительные услуги и админ-инструменты доступны через Кабинет.

## Надёжность
- сервер сериализует изменяющие запросы одного пользователя фиксированным пулом lock-stripes;
- Mini App объединяет одинаковые in-flight запросы и не повторяет mutations автоматически;
- read-only запросы имеют 12-секундный timeout и один retry;
- `db.run_in_transaction()` начинает `BEGIN IMMEDIATE`;
- SQLite WAL: `synchronous=NORMAL`, `wal_autocheckpoint=1000`, `journal_size_limit=64 MiB`;
- `/health/ready` проверяет SQLite и наличие Mini App assets;
- owner получает компактную диагностику ядра в уже существующем разделе Управление;
- background worker пишет heartbeat в `app_meta`.

## Совместимость
Схема пользовательских данных не сбрасывается. Балансы, кампании, задания, история, допуски групп и правила v3.6.x сохраняются.
