# Boostora v3.6.0

## Выпуск

Реализована автоматическая проверка действий Telegram без обязательных скриншотов для новых кампаний.

## Основные изменения

- добавлены события и проверка подписок, вступлений, заявок, реакций, комментариев, сообщений и голосований;
- добавлены `tasks.open` и `tasks.autocheck` для Mini App;
- проверка запускается при возврате в Mini App и при получении события Telegram;
- добавлены кнопки одноразового подключения канала и группы;
- добавлены правила кампании: нужная реакция, минимальная длина, условие, ключевое слово и вариант опроса;
- добавлены миграции кампаний, выполнений и холдов;
- добавлена повторная проверка удержания для членства и реакций;
- снятая реакция/выход отменяют ещё не освобождённую награду;
- тип «Просмотр поста» заменён на честное «Открытие публикации»;
- исправлена привязка события `chat_member` к вступившему пользователю;
- Boostore API сохранён только как дополнительный каталог.

## Проверка

- `python -m compileall -q app` — успешно;
- JavaScript Mini App проверен `node --check` — успешно;
- `pytest -q` — 17 тестов пройдено;
- отдельный тест проверяет начисление, удержание и отмену награды после снятия реакции.

## Ограничения Telegram

Персональное прочтение/просмотр поста Telegram не предоставляет. Удаление обычного комментария также нельзя надёжно перепроверить через Bot API, поэтому длительное удержание применяется только к действиям с доступной проверкой текущего состояния.
