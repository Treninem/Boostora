# Установка PATCH v3.6.5 поверх v3.6.4

1. Остановите Boostora.
2. Сохраните `/app/data/boostora.db`.
3. Распакуйте PATCH в корень проекта с заменой файлов.
4. Не заменяйте рабочий `.env` и не удаляйте `/app/data`.
5. Установите зависимости из обновлённого `requirements.txt`.
6. Во всех группах выдайте Boostora права администратора и **удаление сообщений**.
7. Запустите новый деплой.
8. Проверьте обычного пользователя, отправку от имени канала/анонимного администратора и автоматический форвард канала в discussion group.

Существующие допуски пользователей не сбрасываются.
