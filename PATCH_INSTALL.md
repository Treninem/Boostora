# Установка PATCH v3.6.1 поверх v3.6.0

1. Остановите текущий процесс Boostora.
2. Сохраните копию `/app/data/boostora.db`.
3. Распакуйте PATCH в корень проекта с заменой файлов.
4. Удалите файлы, перечисленные в `DELETE_FILES.txt`.
5. Не заменяйте рабочий `.env` и не удаляйте `/app/data`.
6. Запустите новый деплой.
7. При первом старте старые задания «Запуск бота» и «Открытие Mini App» архивируются автоматически.
8. Неизрасходованные Искры по этим кампаниям возвращаются владельцам.
9. Проверьте список создания кампаний: удалённых типов там быть не должно.

Миграция SQLite выполняется автоматически и повторно средства не возвращает.
