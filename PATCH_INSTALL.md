# Установка PATCH v3.6.3 поверх v3.6.2

1. Остановите Boostora.
2. Сохраните резервную копию `/app/data/boostora.db`.
3. Распакуйте PATCH в корень проекта с заменой файлов.
4. Не заменяйте рабочий `.env` и не удаляйте `/app/data`.
5. При желании добавьте `CHAT_START_GATE_NOTICE_COOLDOWN_SECONDS=15`; без переменной используется значение 15 секунд.
6. Убедитесь, что Boostora остаётся администратором `@Boostorachat` с правом удаления сообщений.
7. Запустите новый деплой.
8. Проверьте: сообщение пользователя без запуска удаляется сразу; повторная быстрая отправка не создаёт пачку предупреждений; после `/start` сообщения проходят.

Уже выданный в v3.6.2 доступ к чату сохраняется.
