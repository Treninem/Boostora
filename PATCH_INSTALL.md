# Установка PATCH v3.4.0

PATCH предназначен для установки поверх **Boostora v3.3.1**.

1. Останови проект на Bothost.
2. Сохрани `/app/data/boostora.db`.
3. Распакуй содержимое PATCH поверх репозитория v3.3.1.
4. Отправь изменения в ветку `main`.
5. Выполни «Новый деплой / Пересобрать».
6. Проверь `/health`, открытие Mini App и одну небольшую тестовую оплату Stars.

Не удаляй `/app/data`. Дополнительный ручной SQL не требуется.
