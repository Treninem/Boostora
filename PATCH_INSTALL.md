# Установка PATCH v3.6.0 поверх v3.5.1

1. Остановите текущий процесс.
2. Сохраните копию `/app/data/boostora.db`.
3. Распакуйте PATCH в корень проекта с заменой файлов.
4. Удалите файлы, перечисленные в `DELETE_FILES.txt`, если список не пуст.
5. Сравните новые параметры `.env.example` со своей конфигурацией.
6. Не заменяйте рабочий `.env` и не удаляйте `/app/data`.
7. Запустите новый деплой.
8. Откройте `/start`, примите новую редакцию соглашения и проверьте Mini App.
9. Выполните минимальную живую проверку покупки Искр, автоматической проверки реакции/подписки и тестового канала.

Миграция SQLite запускается автоматически при старте.
