# Установка PATCH v3.6.2 поверх v3.6.1

1. Остановите Boostora.
2. Сохраните резервную копию `/app/data/boostora.db`.
3. Распакуйте PATCH в корень проекта с заменой файлов.
4. Не заменяйте рабочий `.env` и не удаляйте `/app/data`.
5. Добавьте в Bothost переменные `CHAT_START_GATE_*` из `.env.example` либо оставьте значения по умолчанию.
6. Сделайте Boostora администратором `@Boostorachat` и включите право удаления сообщений.
7. Запустите новый деплой.
8. Убедитесь, что лог содержит `Boostora Chat start gate is ready for @Boostorachat`.
9. Проверьте двумя аккаунтами: сообщение до `/start` удаляется, после `/start` остаётся.

Миграция SQLite выполняется автоматически. Все существующие пользователи должны нажать Start заново один раз после установки этого обновления.
