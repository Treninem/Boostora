# Boostora v3.5.1

## Назначение

Исправление приоритетов интерфейса и пользовательской терминологии поверх v3.5.0.

## Изменения

- Основные разделы Boostora снова стоят первыми: задания и заработок, собственные кампании, сеть рекламных размещений, кошелёк Искр и профиль.
- Каталог готовых Telegram-услуг вынесен в отдельный второстепенный раздел «Дополнительные услуги» и расположен в конце навигации.
- Обычным пользователям не показываются название поставщика, API и внутренняя схема подключения.
- Внутренняя валюта во всех пользовательских экранах, правилах, платежах и уведомлениях называется «Искры».
- Технические имена полей БД и внутренних запросов сохранены для обратной совместимости.
- Владелец по-прежнему управляет дополнительным каталогом и наценкой из закрытого раздела.
- Финальный аудит дополнен отдельной проверкой приоритетов и терминологии Искр.

## Проверки

- 15 автоматических тестов пройдены.
- Синтаксис Python и встроенного JavaScript проверен.
- Финальный аудит: 23 из 23 блоков, 100/100, блокеров нет.
- Миграция базы не требуется.

## Совместимость

Обновление применяется поверх Boostora v3.5.0. Существующая база, балансы, задания, кампании и история операций сохраняются.
