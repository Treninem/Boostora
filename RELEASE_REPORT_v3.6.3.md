# Boostora v3.6.3 — усиленная защита Boostora Chat

## Улучшено

- сообщения пользователей без нового `/start` продолжают удаляться до остальных обработчиков;
- добавлен cooldown предупреждений с кнопкой запуска, чтобы один пользователь не мог заспамить чат служебными сообщениями;
- параллельные обработчики TeleBot не создают дубли предупреждений при серии одновременных сообщений;
- имя бота для deep-link кэшируется после первого определения и не требует `getMe` на каждое удалённое сообщение;
- сообщение об удалении соответствует реальному результату Telegram API; ошибка удаления отдельно пишется в лог;
- cooldown настраивается через `CHAT_START_GATE_NOTICE_COOLDOWN_SECONDS`, по умолчанию 15 секунд.

## Поведение

1. Участник пишет в `@Boostorachat`.
2. Без запуска Boostora сообщение удаляется сразу.
3. Бот упоминает пользователя и показывает кнопку **«🚀 Запустить Boostora»**.
4. Повторные сообщения удаляются, но новое предупреждение не создаётся чаще cooldown.
5. После `/start` старое предупреждение удаляется и сообщения пользователя начинают проходить.

## Bothost

Бот должен быть администратором `@Boostorachat` с правом удаления сообщений. Рабочую БД `/app/data/boostora.db` при обновлении не удалять.
