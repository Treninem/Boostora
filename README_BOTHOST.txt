Boostora для Bothost

1. Загрузите файлы проекта в корень.
2. Создайте файл .env на основе .env.example.
3. Укажите BOT_TOKEN.
4. Для приватного обязательного чата задайте REQUIRED_CHAT_INVITE_LINK.
5. Добавьте бота в обязательный чат. Для самой надежной проверки лучше сделать его админом.
6. Стандартный запуск: main.py в корне.
