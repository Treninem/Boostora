Boostora — Telegram bot launch build for Bothost

1. Upload the project files so that main.py is in the project root.
2. Create .env from .env.example.
3. Fill BOT_TOKEN.
4. Add the bot to the required chat and preferably make it admin.
5. Start the project in Bothost using the standard Python launch.

If your required chat is private, set REQUIRED_CHAT_INVITE_LINK in .env.
