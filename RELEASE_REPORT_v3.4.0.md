# Отчёт релиза Boostora v3.4.0

## Результат

Boostora переведена на самостоятельную Telegram Mini App. Основные пользовательские и управляющие операции выполняются внутри приложения без возврата в чат.

## Реализовано

- SPA-навигация: Главная, Услуги, Работа, Баланс, Профиль;
- Telegram-каталог по папкам и подпапкам;
- оформление и отслеживание заказов;
- кампании заказчика и задания исполнителя;
- кошелёк, пакеты и пользовательская сумма пополнения;
- Standard, PRO и обязательства;
- профиль, роль, язык, рефералы и документы;
- проверка обязательной подписки;
- ручная проверка для администраторов;
- каталог, аналитика и provider-заказы для владельца;
- встроенные Telegram Stars invoices;
- серверная проверка ролей и прав для каждого запроса.

## Безопасность

- `BOT_TOKEN` и `BOOSTORE_API_KEY` не передаются в браузер;
- обычный каталог не содержит закупочного тарифа и наценки;
- скрытие интерфейса дополнено серверным запретом доступа;
- неоплаченный provider-заказ нельзя отправить поставщику;
- owner/admin endpoints защищены отдельно.
