# Boostora v3.7.0

Boostora — Telegram-бот и Mini App для продвижения, выполнения заданий, собственных кампаний и сети рекламных размещений. Основная внутренняя валюта — **Искры**. Каталог дополнительных Telegram-услуг остаётся второстепенным разделом и не заменяет основную механику сервиса.

## Главное в v3.7.0

### Проще снаружи

В Mini App оставлены только три нижние вкладки:

- **Главная** — состояние аккаунта и основные действия;
- **Работа** — задания, кампании и рекламная сеть;
- **Кабинет** — Искры, профиль, режимы, документы, дополнительные услуги и доступные пользователю инструменты.

Новые функции по возможности добавляются внутрь этих разделов, а не отдельными верхними кнопками.

### Жёстче внутри

- изменяющие Mini App-запросы одного пользователя сериализуются на сервере;
- одинаковые запросы в интерфейсе объединяются, чтобы двойной тап не создавал двойную операцию;
- mutations не повторяются автоматически после сетевой ошибки;
- read-only запросы имеют ограниченный timeout и безопасный единичный retry;
- критические SQLite-операции используют `BEGIN IMMEDIATE`;
- вложенные обращения к БД переиспользуют активную транзакцию вместо открытия конкурирующего соединения;
- SQLite работает в WAL с контролируемым checkpoint и лимитом журнала;
- добавлен `/health/ready` для проверки SQLite и файлов Mini App;
- background worker записывает heartbeat;
- владелец получает компактную диагностику ядра в существующем разделе управления.

## Защита групп

Правило действует во всех Telegram `group` и `supergroup`, где присутствует Boostora.

- Пользователь один раз запускает Boostora в личке.
- До запуска его сообщения удаляются, а бот показывает кнопку запуска.
- После подтверждённого `/start` доступ действует во всех группах с Boostora.
- Повторный запуск для каждой группы не нужен.
- Сообщения от имени канала и анонимного администратора не используются как подтверждение запуска конкретного человека.
- Автоматические публикации канала в связанную discussion group не блокируются.

Для строгой работы gate Boostora должна быть администратором группы с правом **удалять сообщения**.

## Автоматическая проверка заданий

Boostora автоматически проверяет только действия, которые Telegram позволяет надёжно связать с конкретным пользователем: подписку/вступление, заявку, реакцию, комментарий, сообщение в чате, поддерживаемое голосование и открытие целевой ссылки/публикации.

Задания «Запуск чужого бота» и «Открытие чужой Mini App» не используются: без интеграции стороннего сервиса их нельзя честно подтвердить.

Для подписок, вступлений и реакций награда может удерживаться до повторной проверки. Снятие действия до окончания удержания отменяет только ещё не освобождённую награду.

## Экономика

- Stars используются для покупки Искр.
- Задания и внутренние услуги оплачиваются Искрами.
- Искры за выполнение заданий выдаются из заранее оплаченного бюджета заказчика.
- Бонусы хранятся отдельно и не превращаются автоматически в Stars.
- Все ручные финансовые изменения владельца должны оставлять историю операции.

## Запуск

Команда:

```bash
python3 main.py
```

Основные данные должны храниться в `/app/data`. Настоящий `.env`, токены и API-ключи нельзя добавлять в GitHub.

После деплоя обязательно проверьте:

1. `/health`;
2. `/health/ready`;
3. `/start` и открытие Mini App;
4. три вкладки **Главная / Работа / Кабинет**;
5. одну тестовую группу с обязательным запуском бота;
6. минимальную тестовую операцию с Искрами;
7. создание и автоматическую проверку тестового задания.

Подробная инструкция для Bothost находится в `BOTHOST_START.md`.

## Надёжность релиза
