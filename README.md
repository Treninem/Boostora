# Boostora — final build

Boostora — Telegram-бот для продвижения внутри Telegram с двумя ролями:

Official bot username: @BoostoraBot
- исполнитель получает задания, зарабатывает внутреннюю валюту и использует награды;
- заказчик создаёт кампании, пополняет баланс и отслеживает результат.

## Что уже есть
- выбор языка при первом запуске;
- 6 языков без смешивания: русский, английский, немецкий, испанский, португальский, турецкий;
- выбор роли: исполнитель или заказчик;
- локализованные меню, команды и экраны;
- внутренняя валюта по языкам:
  - RU — Искры
  - EN — Sparks
  - DE — Funken
  - ES — Chispas
  - PT — Faíscas
  - TR — Kıvılcım
- профиль пользователя;
- кошелёк с доступным балансом, холдом и историей;
- демо-задания;
- взятие задания, отправка на проверку, авто-выпуск наград из холда;
- антифрод и ручная модерация подозрительных выполнений;
- мастер создания рекламных кампаний;
- список кампаний, запуск, пауза, аналитика;
- реферальная система;
- VIP и временные бонусы;
- магазин наград;
- админ-панель через /admin;
- журнал действий админа;
- контур XTR/Telegram Stars для инвойсов;
- помощь /help;
- welcome-баннер и role-баннеры.
- обязательная подписка на чат перед использованием бота.

## Что нужно заполнить перед запуском
Открой `.env.example`, скопируй его в `.env` и заполни:
- `BOT_TOKEN` — токен от BotFather;
- `ADMIN_IDS` — твой Telegram user_id, можно несколько через запятую;
- `SUPPORT_USERNAME` — ник поддержки;
- при необходимости поменяй `BRAND_NAME`;
- `REQUIRED_CHAT_ID` уже проставлен;
- если чат приватный, обязательно укажи `REQUIRED_CHAT_INVITE_LINK`, иначе пользователю будет нечем открыть чат из кнопки.

Пример:
```env
BOT_TOKEN=123456:ABCDEF...
ADMIN_IDS=123456789
DB_PATH=data/boostora.db
BRAND_NAME=Boostora
SUPPORT_USERNAME=@YourSupportBot
DEFAULT_HOLD_HOURS=24
DEMO_HOLD_MINUTES=3
ENABLE_DEMO_TOPUP=1
ENABLE_XTR_PAYMENTS=1
REQUIRED_CHAT_ID=-4998535978
REQUIRED_CHAT_INVITE_LINK=https://t.me/+yourInviteCode
```

## Быстрый запуск
### Windows
1. Установи Python 3.13+
2. Скопируй `.env.example` в `.env`
3. Заполни токен и `ADMIN_IDS`
4. Запусти `run.bat`

### Linux / macOS
1. Скопируй `.env.example` в `.env`
2. Заполни токен и `ADMIN_IDS`
3. Выполни:
```bash
chmod +x run.sh
./run.sh
```

### Ручной запуск
```bash
pip install -r requirements.txt
python -m app.main
```

## Что важно понимать
- это уже сильная рабочая база проекта;
- реальный платёжный поток Telegram Stars требует живого токена и запуска в Telegram;
- прямой вывод Stars пользователю ботом не реализуется через обычный Bot API, поэтому экономика построена на внутреннем reward-балансе, наградах, VIP и рекламных бюджетах;
- демо-пополнение можно отключить через `ENABLE_DEMO_TOPUP=0`.

## Мини-чеклист перед продом
- вписать токен;
- вписать свой `ADMIN_IDS`;
- добавить бота в обязательный чат; лучше сразу сделать его админом для стабильной проверки подписки;
- для приватного чата вставить `REQUIRED_CHAT_INVITE_LINK`;
- поменять ссылки демо-кампаний на свои;
- проверить тексты и бренд;
- включить или выключить demo top-up;
- протестировать `/admin`;
- протестировать XTR invoice-поток в Telegram.

## Структура проекта
- `app/core/` — настройки, локализация, бренд, монетизация;
- `app/handlers/` — хендлеры пользовательских сценариев;
- `app/keyboards/` — клавиатуры;
- `app/storage/` — SQLite-репозитории и работа с БД;
- `assets/banners/` — баннеры;
- `data/` — база данных.
