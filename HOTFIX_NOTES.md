# Boostora v3.6.4 — глобальная защита групп

- Обязательный запуск действует во всех группах и супергруппах с Boostora.
- Один `/start` открывает доступ пользователю сразу во всех таких группах.
- До запуска сообщения удаляются, а пользователю показывается кнопка запуска.
- Для строгого удаления Boostora должна быть администратором каждой группы с правом удаления сообщений.
- Уже выданный доступ не сбрасывается.
