# Boostora v3.4.0 — самостоятельная Mini App

База PATCH: **Boostora v3.3.1**.

- Mini App больше не переводит пользователя обратно в чат для основных операций;
- каталог, заказ услуги, список заказов, кампании, задания, кошелёк, история, профиль, роли, язык, Standard/PRO и документы работают внутри приложения;
- счета Telegram Stars открываются встроенным окном Mini App;
- бот упрощён до входа в приложение и резервной поддержки;
- добавлен единый серверный API `/api/miniapp/query`;
- все запросы повторно проверяют Telegram `initData`, блокировку, документы, подписку, роль, права администратора и владельца;
- внутренний тариф и наценка поставщика не выдаются обычному пользователю;
- управление каталогом и заказами поставщика доступно только владельцу;
- оплаченный заказ поставщика нельзя запустить до подтверждения платежа;
- `BOOSTORE_AUTO_ORDER_ENABLED` теперь реально управляет автоматическим запуском;
- добавлены совместимые поля истории оплаты и запуска provider-заказов;
- сохранены старое ядро, данные и обратная совместимость callback-экранов.

Миграция SQLite выполняется автоматически и только добавляет недостающие поля. Новые обязательные переменные `.env` не требуются.
