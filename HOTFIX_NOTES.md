# Boostora v3.6.3 — усиление защиты Boostora Chat

Обновление поверх **v3.6.2** без сброса уже выданного доступа к чату.

## Что улучшено

- каждое сообщение пользователя без подтверждённого запуска Boostora удаляется первым действием;
- предупреждение с кнопкой запуска ограничено cooldown, поэтому нарушитель не может заспамить чат служебными сообщениями;
- параллельные сообщения одного пользователя не создают дубли предупреждений;
- имя бота для ссылки Start кэшируется после первого получения;
- при ошибке Telegram API бот не сообщает ложно, что сообщение удалено; ошибка фиксируется в логе;
- `CHAT_START_GATE_NOTICE_COOLDOWN_SECONDS=15` позволяет настроить интервал предупреждений.

## Совместимость

Пользователи, уже запустившие Boostora после включения gate в v3.6.2, сохраняют доступ. Нового массового сброса `chat_gate_started_at` в v3.6.3 нет.
