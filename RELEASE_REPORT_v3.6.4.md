# Boostora v3.6.4 — обязательный запуск во всех группах

## Что изменено

- защита запуска больше не ограничена только `@Boostorachat`;
- правило действует во всех обычных группах и супергруппах, где работает Boostora;
- пользователь должен один раз запустить Boostora в личном чате, после чего получает глобальный допуск ко всем группам с ботом;
- если запуск не подтверждён, каждое сообщение удаляется до остальных обработчиков, пользователь упоминается и получает кнопку **«🚀 Запустить Boostora»**;
- личные чаты и каналы не блокируются; комментарии каналов обрабатываются в связанной группе обсуждения как в супергруппе;
- для строгого режима в каждой группе Boostora должна быть администратором с правом удаления сообщений;
- уже подтверждённый запуск из v3.6.2/v3.6.3 сохраняется — повторный `/start` после обновления не требуется.

## Совместимость

Схема SQLite не меняется. Используется существующая отметка `chat_gate_started_at`, поэтому балансы, задания, кампании и история не затрагиваются.
