# Boostora v3.6.2 — обязательный запуск для сообщений в Boostora Chat

## Пользовательский сценарий

1. Любой участник отправляет сообщение в `@Boostorachat`.
2. Если после обновления он ещё не запускал Boostora в личке, исходное сообщение удаляется первым обработчиком.
3. Бот упоминает пользователя и показывает кнопку **«🚀 Запустить Boostora»**.
4. Кнопка открывает личный чат бота с параметром `chat_access`.
5. После настоящего `/start` сервер записывает время запуска, удаляет предупреждение и сообщает, что доступ открыт.
6. Следующие сообщения этого пользователя в `@Boostorachat` пропускаются.

## Что важно

- правило действует и для новых, и для уже состоявших в чате участников;
- старые пользователи Boostora не получают автоматическое исключение: новая колонка миграции изначально пуста;
- перечислять или массово ограничивать всех участников заранее не требуется — проверка происходит при каждой попытке отправить сообщение;
- текст, команды и основные виды медиа перехватываются до остальных обработчиков;
- предупреждения одного пользователя заменяются, чтобы не оставлять дубликаты;
- сообщения ботов не блокируются;
- настройка включена по умолчанию для `@Boostorachat` и может быть изменена через `.env`.

## Новые настройки

```env
CHAT_START_GATE_ENABLED=1
CHAT_START_GATE_CHAT_REF=@Boostorachat
CHAT_START_GATE_CHAT_LINK=https://t.me/Boostorachat
CHAT_START_GATE_START_PARAMETER=chat_access
```

## Права Telegram

Boostora должна быть администратором `@Boostorachat` с правом удаления сообщений. При старте приложение проверяет это право и пишет понятный результат в лог.

## Миграция SQLite

Добавлены:

- `users.chat_gate_started_at` — время подтверждённого личного `/start`;
- `chat_start_gate_notices` — текущее предупреждение пользователя в защищённом чате.

Миграция не удаляет пользователей, кошельки, кампании, задания или историю.

## Проверка

- компиляция Python выполнена;
- отдельно проверена миграция рабочей базы v3.6.1 с сохранением существующего пользователя, роли и risk score;
- 21 автоматический тест пройден;
- отдельно проверены старый пользователь без отметки, мгновенное удаление, упоминание, кнопка deep link, очистка предупреждения и открытие доступа после `/start`;
- реальная живая проверка в Telegram должна быть выполнена после выдачи боту права удаления сообщений.
