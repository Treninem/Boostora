# Boostora v3.0.0-rc1 — prompts for next chat

## Главная подсказка

Продолжай проект Boostora с версии **v3.0.0-rc1**. Это стабильный релиз-кандидат перед финальной **v3.0.0**. Нельзя откатывать функции v2.0.1–v3.0.0-rc1 и нельзя ломать старую базу. Данные должны сохраняться через `BOT_DATA_DIR=/data`.

## Что делать дальше

1. Сначала проверить архив и структуру.
2. Запустить компиляцию всех файлов `app` и `scripts`.
3. Запустить smoke-тесты релиз-центра:
   - `release_candidate_rc1_gate_smoke_test.py`;
   - `release_hardening_smoke_test.py`;
   - `release_candidate_regression_test.py`;
   - `owner_analytics_smoke_test.py`.
4. Если пользователь просит продолжать до v3.0.0, делать только:
   - критические фиксы;
   - UX-полировку;
   - исправление текстов;
   - усиление проверки без ломающей миграции.

## Запреты

- Не добавлять крупные фичи до стабильной v3.0.0.
- Не менять смысл внутренней валюты: **Искры ✨**.
- Не включать `.db`, `storage`, `__pycache__`, `.pyc` в пользовательский архив.
- Не ломать Bothost-запуск через `python3 main.py`.
