# Boostora v3.0.0 — память для переноса

Текущая версия: **Boostora v3.0.0**.

Это стабильный коммерческий релиз после `Boostora v3.0.0-rc1`. Нельзя откатывать функции v2.0.1–v3.0.0-rc1.

Ключевые сохранённые блоки:

- Искры ✨, кошелёк, Stars, VIP.
- Создание заданий 1/3–3/3.
- Экономический советник цены.
- Кабинет заказчика и ускорение задания.
- Trust-engine.
- Админка, риск-очередь, шаблоны решений.
- Антифрод-заметки и паттерны.
- Live-аудит прав бота.
- Реклама во все чаты.
- Коммерция владельца.
- Релиз-центр: stable gate, rc1-gate, guardrails, regression pack.

Важное правило: хранение старых данных через `BOT_DATA_DIR=/data`; не делать ломающих миграций. Следующая версия должна быть **v3.0.1** и содержать только фиксы/полировку.
