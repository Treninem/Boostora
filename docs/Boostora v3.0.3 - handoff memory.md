# Boostora v3.0.3 — перенос в новый чат

Текущее состояние проекта: **Boostora v3.0.3**.

Это стабильный патч поверх **v3.0.2** без отката функций и без ломающей миграции.

## Что обязательно помнить

- Архитектура стабильной ветки v3.0.x сохранена.
- Старые данные пользователей должны сохраняться.
- Основной путь хранения: `BOT_DATA_DIR=/data`.
- Нельзя включать в пользовательский архив `storage`, `.db`, `.pyc`, `__pycache__`.
- Любые следующие версии v3.0.4+ должны быть только патчами без крупных новых функций и без ломающих миграций.

## Что добавлено в v3.0.3

- SQLite runtime hardening:
  - `timeout=30`;
  - `PRAGMA busy_timeout = 5000`;
  - безопасный `PRAGMA journal_mode = WAL`.
- Новый read-only runtime guard в релиз-центре.
- Проверка зависших вводов, старых инвойсов, просроченных холдов и рекламного backlog.
- Новый stable gate row: `runtime_safety`.
- Новый stable contract пункт: `stable_contract_patch_303_policy`.
- Новый тест: `scripts/stable_patch_v303_smoke_test.py`.

**Boostora v3.0.4**.
