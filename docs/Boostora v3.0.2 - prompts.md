# Boostora v3.0.2 — подсказки для продолжения

## Короткая команда

Продолжай Boostora с версии **v3.0.2**. Делай только стабильные патчи без ломающей миграции. Старые данные должны сохраняться через `BOT_DATA_DIR=/data`.

## Что помнить

- Это уже стабильная коммерческая ветка.
- Пользователь хочет два архива:
  - архив для тебя с ТЗ, памятью, подсказками и документами;
  - архив с ботом для пользователя.
- Пользовательский архив должен быть чистым: без `storage`, `.db`, `.pyc`, `__pycache__`.
- Нужно проверять скачиваемость и целостность архивов.
