# Boostora v3.0.0-rc1 — roadmap

## Сейчас готово

- Основной пользовательский путь.
- Кошелёк, Искры, Stars-пополнение.
- VIP.
- Создание заданий.
- Экономика цены/скорости.
- Кабинет заказчика.
- Ускорение заданий.
- Исполнительские задания и proof.
- Hold-награды.
- Ручная проверка.
- Антифрод.
- Реклама во все чаты.
- Права бота по чатам.
- Коммерческая аналитика владельца.
- Релиз-центр и RC1-gate.

4. Оплатить тестовое задание.

6. Выполнить задание исполнителем.

8. Разобрать заявку через шаблоны.

11. Отправить тестовую рекламу во все чаты.
12. Сверить коммерцию владельца.
13. Проверить RC1-gate в релиз-центре.
