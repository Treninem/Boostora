# Boostora v3.0.2 — changelog

## Тип версии

Стабильный патч поверх **Boostora v3.0.1**.

- Без отката функций.
- Без ломающей миграции.
- Без новых обязательных таблиц.
- Старые данные должны сохраняться через `BOT_DATA_DIR=/data`.

## Что изменено

### 1. Runtime safety

Добавлена защита от зависшего polling-lock:

- lock-файл теперь хранит PID и время создания;
- при новом старте бот проверяет, жив ли процесс из lock-файла;
- если процесс уже не жив, stale lock удаляется;
- если процесс жив, второй polling не запускается.

### 2. Persistence safety в релиз-центре

В stable gate добавлена строка **Хранение /data и резервные копии**.

Проверяется:

- существует ли каталог данных;
- существует ли родительская папка базы;
- находится ли база внутри каталога данных;
- количество startup-backup файлов;
- наличие файлов в `invalid-db`.

### 3. Тексты и релиз-центр

Обновлены:

- экран релиз-центра владельца;
- `/version`;
- админ-центр;
- коммерция владельца;
- stable contract.

### 4. Проверки

Добавлен тест:

```bash
/usr/bin/python3 scripts/stable_patch_v302_smoke_test.py
```

Также проверяются предыдущие стабильные smoke-тесты.
