# Boostora v3.0.0-rc1 — handoff memory

Текущая версия: **Boostora v3.0.0-rc1**.

Это продолжение **v2.7.0** без отката функций и без ломающей миграции.

## Главный фокус

Закрепить стабильный релиз-кандидат перед публичной **Boostora v3.0.0**.

## Что уже есть в ветке

- Trust-engine.
- Умный лимит активных заданий: VIP + доверие.
- Экономический советник цены.
- Кабинет заказчика.
- Ускорение задания через доплату.
- Реклама во все чаты.
- Админка с риск-очередью, шаблонами решений и массовыми безопасными действиями.
- Live-аудит прав бота.
- Антифрод-заметки и паттерны.
- Коммерческая аналитика владельца.
- Релиз-центр с launch guardrails.
- Новый RC1-gate и RC1-договор.

## Важно для следующего чата

- Не откатывать функции v2.0.1–v3.0.0-rc1.
- Не делать ломающую миграцию.
- Сохранять старые данные через `BOT_DATA_DIR=/data`.
- До стабильной v3.0.0 добавлять только критические фиксы, безопасную UX-полировку и уточнения текстов.
- Перед стабильной v3.0.0 нужен живой regression: Stars, VIP, создание/оплата/ускорение задания, proof, hold, ручная проверка, реклама, права бота, коммерция владельца.

## Следующая цель

**Boostora v3.0.0**:

- исправить найденные live-блокеры;
- подтвердить 24 часа без критических ошибок;
- финально отполировать тексты;
- собрать стабильный архив.
