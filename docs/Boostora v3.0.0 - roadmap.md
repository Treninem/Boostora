# Boostora v3.0.0 — roadmap

## Текущее состояние

Стабильный коммерческий релиз готов как база.

## Дальше

### v3.0.1

- исправления критических ошибок;
- UX-полировка;
- расширение regression pack;
- уточнение текстов;

- усиление живого мониторинга;
- больше отчётов владельца;
- аккуратное улучшение антифрода;
- сохранение совместимости `/data`.

### v3.1.0

Только после стабильной эксплуатации v3.0.x: новые функции можно добавлять отдельно и осторожно.
