# Boostora v3.0.1 — handoff memory

Текущая версия: **Boostora v3.0.1**.

Это стабильный патч после v3.0.0. Не откатывать функции v3.0.0: Stars, VIP, задания, ускорения, proof/hold, антифрод, админ-центр, коммерция владельца, релиз-центр и `/data`-совместимость должны остаться.

Главный фокус v3.0.1:

- безопасный разбор `.env`;
- защита от падения при криво заполненных `ADMIN_IDS` и числовых настройках;
- проверка целостности кошельков, резервов кампаний и холдов;
- UX-тексты стабильного патча;
- никаких ломающих миграций.

Следующая логичная версия: **Boostora v3.0.2** — только критические фиксы, UX-полировка и новые проверки без крупных функций.
