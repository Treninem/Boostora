# Boostora v3.0.1 — changelog

## Тип версии

Стабильный патч поверх Boostora v3.0.0.

## Сделано

- Версия поднята до `Boostora v3.0.1`.
- `APP_STAGE='stable_patch'`.
- Безопаснее разобран `.env`: неверные `ADMIN_IDS` и числовые параметры не должны ломать старт всего бота.
- В stable gate добавлены проверки целостности денег и холдов.
- Обновлены тексты админки, коммерции владельца и релиз-центра.
- Добавлен smoke-тест `stable_patch_v301_smoke_test.py`.

## Миграции

Ломающей миграции нет. Новых обязательных таблиц нет.

## Данные

Старые данные должны сохраняться через `BOT_DATA_DIR=/data`.
