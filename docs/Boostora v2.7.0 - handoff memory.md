# Boostora v2.7.0 — handoff memory

Текущая версия: **Boostora v2.7.0**.

Это продолжение **v2.6.0** без отката функций и без ломающей миграции.

## Главный фокус

Финальная предрелизная закалка и подготовка к **Boostora v3.0.0-rc1**.

## Что появилось

- Релиз-чек стал **Релиз-центром**.
- Добавлены launch guardrails:
  - блокеры схемы и `.env`;
  - живой Stars-платёж;
  - VIP-сценарий;
  - оплата/ускорение задания;
  - права бота;
  - ручная очередь;
  - high-risk без блока;
  - активные задания.
- Добавлен финальный чек-лист перед v3.0.0-rc1.
- Добавлен smoke-тест `release_hardening_smoke_test.py`.

## Важно

- Старые данные сохранять через `BOT_DATA_DIR=/data`.
- Не добавлять крупные фичи перед v3.0.0 без крайней необходимости.
- Следующий логичный шаг — **v3.0.0-rc1**.
- Перед rc1 обязательно нужен ручной live regression: Stars, VIP, задание, ускорение, proof, hold, админка, реклама, права бота, коммерция владельца.

## Следующая цель

**Boostora v3.0.0-rc1**:

- финальная UX-полировка;
- фиксы только критических ошибок;
- живой regression pack;
- подготовка стабильного коммерческого релиз-кандидата.
