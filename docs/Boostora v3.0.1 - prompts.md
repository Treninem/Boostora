# Boostora v3.0.1 — prompts

Продолжать от Boostora v3.0.1.

Ключевые правила:

- не откатывать функции v3.0.0;
- не ломать старую базу;
- сохранять `BOT_DATA_DIR=/data`;
- пользовательский архив не должен содержать `storage`, `.db`, `.pyc`, `__pycache__`;
- версии после v3.0.1 делать как патчи, пока пользователь явно не попросит крупную v3.1.0.

Следующий фокус: v3.0.2 — критические фиксы, UX-полировка, дополнительные проверки, без крупных новых функций.
