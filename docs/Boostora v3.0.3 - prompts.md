# Boostora v3.0.3 — подсказки для продолжения

## Основная команда

Продолжай проект Boostora с версии **v3.0.3**. Делай только стабильные патчи без ломающей миграции. Старые данные пользователей должны сохраниться через `BOT_DATA_DIR=/data`.

## Правила

- Не откатывать функции.
- Не включать `storage`, `.db`, `.pyc`, `__pycache__` в пользовательский архив.
- Перед выдачей архивов проверять компиляцию, smoke-тесты и zip integrity.
- Видимые тексты для пользователей — аккуратные, без служебного мусора.
- Служебная диагностика — только для владельца/админки.

## Следующая цель

Boostora v3.0.4: UX-полировка, расширение диагностики, дополнительные проверки и сохранение старых данных.
