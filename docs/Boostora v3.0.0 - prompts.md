# Boostora v3.0.0 — подсказки для продолжения

Продолжать только поверх **Boostora v3.0.0**.

Главное правило: не откатывать функциональность и не ломать старую базу. Все новые изменения должны сохранять `BOT_DATA_DIR=/data`.

Формат следующих ответов пользователю:

1. Архив для тебя, с ТЗ, памятью, подсказками и т.д.
2. Архив с ботом для меня.
3. Описание проделанной работы.
4. Что проверено.
5. Следующий план.

Следующая логичная версия: **Boostora v3.0.1**.
