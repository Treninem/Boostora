# Boostora v3.0.3 — roadmap

## Статус

**v3.0.3** — стабильный runtime-патч.

## Сделано

- Runtime-защита SQLite.
- WAL/busy-timeout.
- Проверка зависших очередей.
- Релиз-центр v3.0.3.
- Smoke-тест v3.0.3.

## Дальше: Boostora v3.0.4

Только патчи:

1. UX-полировка сообщений ошибок.
2. Более аккуратные подсказки владельцу в релиз-центре.
3. Дополнительные read-only проверки для платежей и рекламных задач.
4. Live-regression по Bothost.
5. Без ломающих миграций.

## Запрещено в v3.0.x без отдельного решения

- Ломать схему базы.
- Менять смысл старых таблиц.
- Удалять старые поля.
- Откатывать trust-engine, кабинет заказчика, админку, антифрод, рекламу во все чаты, коммерцию владельца или релиз-центр.
