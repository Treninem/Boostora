## Краткая подсказка для продолжения

Продолжай проект Boostora с версии **v2.7.0**. Это финальная предрелизная ветка перед **v3.0.0-rc1**. Нельзя откатывать функции v2.0.1–v2.7.0 и нельзя ломать старую базу. Данные должны сохраняться через `BOT_DATA_DIR=/data`.

## Что делать дальше

Собрать **Boostora v3.0.0-rc1**:

- не добавлять крупные новые модули;
- пройтись по UX;
- исправить только критические ошибки;
- усилить подсказки там, где пользователь может застрять;

- пользовательский архив не должен содержать `__pycache__`, `.pyc`, `.db`, `storage`.
